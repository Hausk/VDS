# Libre&Vivant Monorepo

Ce projet regroupe les trois applications interconnectées :

- `vitrine/` : Site public
- `dashboard/` : Interface admin
- `panel/` : Interface client

Chaque projet est 100% typé avec [TypeScript](https://www.typescriptlang.org/).

### Technologies

- Next.js (App Router)
- Prisma, PostgreSQL
- Tailwind CSS, shadcn/ui
- Turborepo

### Installation

```sh
git clone https://github.com/hausk/VDS.git
cd monorepo-lvivant
pnpm install
```

### Lancer le projet

```sh
cd mon-repo
pnpm dev
```

### Build le projet

```sh
cd mon-repo
pnpm build
```
